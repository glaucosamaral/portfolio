# Portfolio Pessoal

Meu portfólio pessoal desenvolvido com HTML5 e CSS3 puro.

## Funcionalidades

- Seção "Sobre mim"
- Lista de habilidades
- Cards de projetos
- Formulário de contato
- Design responsivo (mobile-first)

## Tech Stack

- HTML5
- CSS3 (Flexbox / Grid)

## Como rodar

Abra o arquivo `index.html` no navegador ou use o Live Server no VS Code.
